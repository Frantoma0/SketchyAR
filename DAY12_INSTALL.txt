SketchyAR Day 12 — v0.12.0
Основа: работещ SketchyAR Day 11 v0.11.0.

ПРЕПОРЪЧИТЕЛНО: изтегли SketchyAR_Day12_Patch.zip и разархивирай
съдържанието в корена на твоя ar-drawing проект. Запази Git историята си.

1. Провери дали patch-ът се прилага (преди да променяш файлове):

  git status --short
  git apply --check SketchyAR_Day12_NMS_Hysteresis.patch
  git apply SketchyAR_Day12_NMS_Hysteresis.patch

  Ако check даде грешка: СПРИ. Не ползвай -f и не заменяй styles.css.

2. Windows тестове:

  python -m pytest python_engine -q
  python scripts/day12_benchmark.py --sizes 512 1024 --runs 5
  python scripts/day12_preview.py
  python scripts/day12_compare_cv2.py

  # optional: използвай собствени снимки; не ги качвай в GitHub:
  python scripts/day12_preview.py --input "C:\photos\portrait.jpg" "C:\photos\object.jpg"

  cd app
  npm ci
  npm run typecheck
  npm run build
  cd ..

3. Публикувай само ако горните команди минат:

  git add .
  git commit -m "Day 12: NumPy NMS hysteresis edge pipeline"
  git push origin main

4. На iPhone провери commit / v0.12.0 в диагностиката; натисни
"Тествай Day 12 · 512 px", после "Тествай Day 12 · 1024 px".
Експортирай диагностика и сравни:

  python scripts/day12_compare_device.py experiments/outputs/day12-cpython-benchmark.json "C:\path\to\sketchyar-diagnostics.json"

5. Провери Home, 5+ полароида и скрол, камера, Lock, Mirror,
Opacity 0-100%, autosave/restore. Без изтриване или преинсталиране
на PWA; backup/restore предстои.

ВАЖНО:
- Това е Canny-подобен алгоритъм, не 1:1 cv2.Canny.
- Не се правят промени на Camera UI или IndexedDB.
- Pyodide/NumPy са самохоствани както преди; не добавяме cv2/SciPy.
- Фото настройките са експериментални; F може да изгуби важен силует.
- Пълният Vite build не е потвърден в средата на генериране.
