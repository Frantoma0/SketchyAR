SketchyAR — Ден 32.1 / v0.32.1 — iPhone AI Lab (изследователски експеримент)

Изходен проект: v0.32.0. PATCH: разархивирай в корена ar-drawing/ и потвърди замяната на файлове.
Пълният ZIP съдържа коренна папка ar-drawing/. НЕ изтривай .git или локални проекти.

Проверки (ако работиш с GitHub Actions за build, можеш да оставиш CI да ги изпълни):
  cd app
  npm ci --include=dev
  npm run typecheck
  npm run build
  npm run test:iphone-ai
  cd ..
  python -m pytest python_engine -q

Качи в GitHub Pages. На iPhone отвори в Safari адреса на приложението с /ai-lab/ отзад.
Пример: https://USERNAME.github.io/REPO/ai-lab/

Натисни Инсталирай / зареди модела (първоначално нужен интернет), после синтетично изображение,
128 px и Генерирай и измери. По-късно 256/384 px. Експортирай JSON отчета и го изпрати за анализ.

ЗАБЕЛЕЖКИ:
- Това е РЕАЛЕН AI бенчмарк на iPhone, а не нов завършен Manga бутон.
- Зависимостите за браузърното AI се изтеглят и кешират при първата инсталация.
- Снимките не се качват на сървър; без облачен inference.
- Дистрибуцията не съдържа тегла и не предоставя комерсиално разрешение.
- Browser WebGL/TF.js 4.x compatibility на реален iPhone още НЕ е потвърдена.
