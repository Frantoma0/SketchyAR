SketchyAR v0.32.2 — Day 32.2: iPhone AI Lab SAFE tiled inference
============================================================

Това е пълна версия / patch върху v0.32.1. Не изтривай `.git`, оригинали,
местната база IndexedDB или проекта. Няма промяна по основния Manga бутон.

ИНСТАЛАЦИЯ (Windows)
1. Patch ZIP: разархивирай СЪДЪРЖАНИЕТО върху корена `ar-drawing/`.
   Full ZIP: разархивирай и копирай съдържанието на вложената `ar-drawing/`
   директория в съществуващата Git папка `ar-drawing/`. Не прави вложено
   `ar-drawing/ar-drawing/` и не изтривай `.git`.
2. В PowerShell от корена на проекта:

   cd app
   npm ci --include=dev
   npm run typecheck
   npm run build
   npm run test:iphone-ai
   cd ..
   python -m pytest python_engine -q

3. Ако тестовете са успешни:

   git status
   git add -A
   git commit -m "fix: Day 32.2 iPhone safe tiled AnimeGAN and crash checkpoint"
   git push origin main

4. След успешна GitHub Pages публикация отвори `/ai-lab/` на iPhone.
   Обнови страницата (понякога два пъти заради стария Service Worker), докато
   заглавието показва "Ден 32.2". Инсталирай/зареди AI модела от локалния кеш.
5. Тествай 192px, 256px; ако работят — 384px (плочки), и едва след това 512px.
   При всяка стъпка запази JSON; не се очаква 384/512 да са по-бързи.

Безопасност:
- При 384/512 px никога не се изпълнява моделът върху цялата снимка наведнъж.
- Плочките имат максимум 192x224 = 43 008 входни пиксела (площта на успешния
  експеримент 168x256), припокриват се и се смесват на CPU.
- Това НЕ е benchmark за по-голям AI модел. Възможни са видими шевове.
- iOS Safari може да прекрати процес и без JS грешка — не гарантираме
  предотвратяване на срив или възстановяване на загубения WebGL context.
- При прекъсване AI Lab записва само технически checkpoint, а не снимки.
- Промените не засягат основната камера, скица/Манга V1 или ZIP v1 schema.
